# Global Energy & Climate Impact Predictor

This project predicts future:
- Primary energy consumption
- CO2 emissions

It uses historical country-level data, builds ML models, serves predictions with FastAPI, and provides a Streamlit frontend.

## What This Project Does

1. Cleans raw OWID climate/energy data
2. Creates lag features for time-based prediction
3. Trains two models:
- Energy model: Ridge Regression
- CO2 model: Random Forest Regressor
4. Saves trained models in the top-level model/ folder (outside src/)
5. Exposes a prediction API
6. Displays forecasts in a simple web dashboard

## Project Structure

- data/
- owiddata.csv (raw data)
- cleaned_owiddata.csv (processed data generated by ETL)
- model/
- energy_model.pkl
- co2_model.pkl
- src/
- etl.py (data cleaning + feature engineering)
- train.py (model training)
- app/
- main.py (FastAPI API)
- frontend.py (Streamlit UI)
- Dockerfile, Dockerfile.frontend, docker-compose.yml

## Setup

Install dependencies from the project root:

```bash
pip install -r requirements.txt
```

## Run Pipeline (Local)

From project root:

```bash
python src/etl.py
python src/train.py
```

These commands will:
- generate data/cleaned_owiddata.csv
- save trained models in model/

## Run Backend API

From project root:

```bash
uvicorn app.main:app --reload
```

API will run at:
- http://127.0.0.1:8000

Health check:
- GET /

Prediction endpoint:
- POST /predict
- params: country, target_year

Example:

```bash
curl -X POST "http://127.0.0.1:8000/predict?country=Sri Lanka&target_year=2035"
```

## Run Frontend

From project root:

```bash
streamlit run app/frontend.py
```

Optional API URL override:

```bash
set API_URL=http://127.0.0.1:8000
streamlit run app/frontend.py
```

## Docker

From project root:

```bash
docker-compose up --build
```

## Notes

- Train models after running ETL so cleaned data exists.
- Models are intentionally saved outside src/ in model/ for cleaner separation of code and artifacts.
- If prediction says country not found, check country names from cleaned dataset.
